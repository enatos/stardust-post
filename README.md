# ✦ 星屑ポスト (Stardust Post) v1.2.1

思考の蒸発を防ぐ常設クイック入力システム（Web/PWA & Google Apps Scriptバックエンド）。

---

## 1. システム構成と機能

```text
[ スマホ PWA / PCブラウザ / iOSショートカット ]
                      │ （いつでも投函）
                      ▼
            ┌──────────────────┐
            │   星屑ポスト      │
            └──────────────────┘
                      │ POST (Content-Type: text/plain)
                      ▼
     [ GAS Web App: doPost(e) / doGet(e) ]
                      │ 排他制御（スクリプトロック）& 冪等性保証
                      ▼
  [ Googleスプレッドシート: stardust_inbox ]
                      ▲
                      │ 取得 & トリアージ更新 (doGet / doPost)
                      ▼
            ┌──────────────────┐
            │  ぽらりす入力UI   │
            └──────────────────┘
```

- **構造化クイック入力**:
  - **やること（`todo`）**: 必須、最大150文字（カウンター付き）
  - **プロジェクト（`project`）**: スプレッドシート `project_master` から休眠・卒業を除いて自動取得
  - **担当AIちゃん（`assigned_ai`）**: なびさん、くろさん、ジェミさん、じょじょ、カニ様、エビ様、かーくん、魚氏、その他
  - **メモ（`memo`）**: 任意、最大500文字（複数行・カウンター付き）
- **完全オフライン対応**: 通信切断時は `IndexedDB`（`outbox_queue`）へ自動退避し、オンライン復帰時に1件ずつ自動再送。プロジェクトマスターもIndexedDBへキャッシュ。
- **共有シークレット認証**: 公開コードに秘密情報を埋め込まず、初回起動時に端末内 `IndexedDB`（`settings`）へ保存・検証。
- **堅牢なバックエンド**: スクリプトロックによる直列化、ULID（26文字）による冪等な追記（二重投稿防止）。
- **安全な列移行**: 旧10列の `stardust_inbox` は、既存値を保持したまま13列へ自動移行します。想定外の列構造では書き込みを停止します。
- **日本時間の正規化**: `created_at` は実時刻と一致する `Asia/Tokyo` のISO 8601形式で記録します。

## 2. デプロイ手順

### A. Google Apps Script (GAS) のセットアップ
1. 対象のスプレッドシート（ぽらりす用スプレッドシート）を開きます。
2. メニュー `拡張機能` → `Apps Script` を選択。
3. `Code.gs` の内容を `stardust-post/gas/Code.gs` のコードに置き換えて保存します。
4. **シークレットの設定**:
   - 左メニューの `プロジェクトの設定`（歯車アイコン）を開きます。
   - `スクリプト プロパティ` に以下を追加します:
     - プロパティ: `STARDUST_TOKEN`
     - 値: `<あなたが決めた共有シークレット文字列>`
5. **Web App としてデプロイ**:
   - 右上の `デプロイ` → `新しいデプロイ`（または既存デプロイの更新）を選択。
   - 種類: `ウェブアプリ`
   - 説明: `星屑ポスト Web API v1.2`
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員（匿名を含む）**
   - デプロイを実行し、発行された **ウェブアプリのURL** をコピーします。

## 3. スプレッドシート `stardust_inbox` 列構成

| 列番号 | 列名 | 型 | 説明 |
| :--- | :--- | :--- | :--- |
| A (1) | `post_id` | 文字列 (ULID) | 星屑の一意ID（主キー） |
| B (2) | `todo` | 文字列 | やること（最大150文字） |
| C (3) | `project` | 文字列 | プロジェクト名 |
| D (4) | `assigned_ai` | 文字列 | 担当AIちゃん |
| E (5) | `memo` | 文字列 | メモ（最大500文字） |
| F (6) | `created_at` | 文字列 (ISO 8601) | 投稿日時（端末時計） |
| G (7) | `received_at` | 文字列 (ISO 8601) | GAS受信日時（並び順の正本） |
| H (8) | `source` | 文字列 | `web_pwa`, `ios_shortcut`, `mac_web` 等 |
| I (9) | `status` | 文字列 | `inbox`, `imported`, `hold`, `dismissed` |
| J (10) | `imported_work_date` | 文字列 (YYYY-MM-DD) | タスク化された開店日 |
| K (11) | `imported_task_id` | 文字列 (ULID) | ぽらりす側タスクID |
| L (12) | `processed_at` | 文字列 (ISO 8601) | トリアージ処理日時 |
| M (13) | `updated_at` | 文字列 (ISO 8601) | 最終更新日時 |

---

## 4. テストの実行

```bash
node tests/run_all.js
```

`run_all.js` で、認証前のシート非変更、旧10列から13列への安全な移行、投稿の冪等性、トリアージ更新、日次データと今日のゴールの取得、日本時間変換、公開ファイル内の秘密情報・個人情報の静的検査をまとめて確認します。
